# Art Avenue Studio — Подключение к базе данных и хранилищу

Сайт уже подключен к Vercel и деплоится автоматически при пуше в этот репозиторий. Проект полностью переведен на бессерверную архитектуру!

Осталось сделать только два шага для того, чтобы база данных и картинки начали работать на живом сайте.

## Шаг 1: Создание Базы Данных (Turso)
Поскольку Vercel не хранит файлы, нам нужна бесплатная облачная база данных Turso (это тот же SQLite, но в интернете).

1. Зарегистрируйтесь на [turso.tech](https://turso.tech/) (через GitHub).
2. Создайте новую базу данных (кнопка `Create Database`).
3. Скопируйте **Database URL** (он выглядит как `libsql://...`).
4. Нажмите **Generate Token** и скопируйте его.
5. Зайдите в панель управления вашего проекта на **Vercel** -> **Settings** -> **Environment Variables**.
6. Добавьте туда:
   - `TURSO_DATABASE_URL` = Вставьте ваш URL
   - `TURSO_AUTH_TOKEN` = Вставьте ваш Токен
   - `JWT_SECRET` = Придумайте любой сложный пароль на английском (от 32 символов) — это нужно для безопасности токенов авторизации.

## Шаг 2: Инициализация таблиц
После того как вы создали базу в Turso, она абсолютно пустая. Нам нужно создать в ней таблицы для админки.
Прямо на вашем компьютере:
1. Откройте файл `.env` (в корне папки с сайтом) и впишите туда ваши `TURSO_DATABASE_URL` и `TURSO_AUTH_TOKEN`.
2. Откройте терминал PowerShell в папке с сайтом и выполните команду:
   ```bash
   node -e "import('./server/initDb.js')"
   ```
Всё! У вас появится администратор с паролем `3dmodelki`.

## Шаг 3: Настройка хранилища (Vercel Blob)
Чтобы в админке можно было загружать картинки и 3D-модели прямо на сервер:
1. Зайдите в Vercel в ваш проект -> вкладка **Storage**.
2. Нажмите **Create Database** и выберите **Vercel Blob**.
3. Создайте хранилище и нажмите **Connect** к вашему проекту.
Vercel сам автоматически добавит все нужные ключи для картинок!

🎉 **Готово! Ваш сайт полностью работает в интернете с рабочей админкой.**
