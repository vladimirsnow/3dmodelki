# Art Avenue Studio — Руководство по развертыванию на Vercel

Этот проект полностью оптимизирован для бесплатного serverless-деплоя на платформе **Vercel** с использованием облачной базы данных **Turso** (SQLite) и облачного хранилища **Vercel Blob** (для картинок и 3D-моделей).

## 🚀 Пошаговая инструкция по запуску в интернет

### Шаг 1: Загрузка кода на GitHub
1. Создайте пустой репозиторий на [GitHub](https://github.com/).
2. Откройте терминал в папке с вашим сайтом.
3. Выполните команды:
   ```bash
   git init
   git add .
   git commit -m "Готово к продакшену"
   git remote add origin https://github.com/ВАШ_ЛОГИН/НАЗВАНИЕ_РЕПОЗИТОРИЯ.git
   git branch -M main
   git push -u origin main
   ```

### Шаг 2: Создание Базы Данных (Turso)
1. Зарегистрируйтесь на [turso.tech](https://turso.tech/) (через GitHub).
2. Создайте новую базу данных.
3. Скопируйте **Database URL** (будет выглядеть как `libsql://...`).
4. Сгенерируйте токен доступа (**Auth Token**).

### Шаг 3: Деплой на Vercel
1. Перейдите на [Vercel](https://vercel.com/) и войдите через GitHub.
2. Нажмите **"Add New..." -> "Project"** и выберите ваш репозиторий Art Avenue Studio.
3. Оставьте настройки Framework Preset как `Vite`.
4. В разделе **Environment Variables** (переменные окружения) добавьте следующие ключи:
   - `TURSO_DATABASE_URL` = Вставьте ваш URL из шага 2
   - `TURSO_AUTH_TOKEN` = Вставьте ваш Токен из шага 2
   - `JWT_SECRET` = Придумайте длинный сложный пароль (минимум 32 символа, например: `super_secret_jwt_key_artavenue_2026_xyz`)
5. Нажмите **Deploy**.

### Шаг 4: Настройка хранилища файлов (Vercel Blob)
Чтобы админ мог загружать новые картинки и 3D модели прямо на живом сайте:
1. В панели управления вашего проекта на Vercel перейдите на вкладку **Storage**.
2. Создайте новое хранилище **Vercel Blob**.
3. Привяжите его к вашему проекту (Connect).
4. Vercel автоматически добавит токен `BLOB_READ_WRITE_TOKEN` в ваши переменные окружения.

### Шаг 5: Инициализация базы данных
Поскольку база данных в Turso пустая, при первом заходе вам нужно будет выполнить скрипт инициализации, чтобы создать таблицы.
В папке проекта на вашем компьютере:
1. Откройте файл `.env` и впишите туда ваши `TURSO_DATABASE_URL` и `TURSO_AUTH_TOKEN`.
2. В терминале выполните: `node -e "import('./server/initDb.js')"`
Это создаст таблицы и администратора прямо в облаке Turso!

🎉 **Готово! Ваш сайт полностью работает в интернете с рабочей админкой.**

- **SEO**: Сайт полностью проиндексирован под ключевые слова "3D дизайн, архитектурная визуализация, Unreal Engine 5". Настроен `sitemap.xml`, `robots.txt`, Open Graph и Schema.org.
